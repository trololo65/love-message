НЕБОЛЬШАЯ ИСТОРИЯ ДЛЯ ЯНЫ

СТРУКТУРА
- index.html — разметка и этапы истории;
- styles.css — оформление, дождь, мобильная адаптация и анимации;
- app.js — переходы, вопросы, котята, музыка и открытие письма;
- assets/images/ — оригинальные изображения обложек альбомов;
- assets/music/ — аудиофайлы.

КАК ЗАПУСТИТЬ
Оставьте структуру папок без изменений. Для локального теста можно открыть index.html, но для наиболее надёжной работы аудио и путей лучше запустить проект через локальный сервер или разместить на хостинге (например, `python3 -m http.server 8000`).

ПОВЕДЕНИЕ ПЛЕЕРА
- Сразу при входе сначала загружается Lonely Day. После появления первых аудиоданных начинается загрузка всех обложек, а затем — остальных треков по очереди. Это происходит заранее, ещё на первом экране.
- Lonely Day пытается автоматически запуститься при загрузке.
- Браузеры часто блокируют autoplay со звуком. Если это произошло, сайт повторит запуск при первом касании/клике пользователя — это стандартное ограничение iOS/Safari и других браузеров.
- Нажатие на обложку запускает выбранную песню.
- Повторное нажатие на ту же обложку переключает обратно на Lonely Day.
- Позиция воспроизведения каждой композиции запоминается отдельно в localStorage и восстанавливается при следующем выборе.
- Если выбранная песня заканчивается, возобновляется Lonely Day.
- Встроенных контролов и перемотки нет.
- Для смены формата аудио (например, на .m4a) обновите пути в объекте trackFiles в app.js.

Позиции воспроизведения сохраняются в браузере на этом устройстве. При очистке данных сайта они сбросятся.
